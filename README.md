A Rust-based command-line tool for **code generation from user-defined templates**. It supports [Handlebars](https://handlebarsjs.com/) templating, allowing users to scaffold files and projects quickly and consistently using customizable templates. Inspired by plop.js.

## ✨ Features

- 🔧 Generate boilerplate code using templates
- 🧩 Easy generator declaration using YAML
- ⚙️ User-friendly CLI interface
- 🚀 Fast and lightweight (native Rust performance)

## 🛠️ Roadmap for this project

- [ ] Adding extra configuration (flags, action types)
- [ ] Global templates index (able to use generators in any project)
- [ ] Available on every package managers and operating systems

## 📦 Installation

### Build from source

```bash
git clone https://github.com/NDJafu/oku.git
cd oku
cargo build --release
```
